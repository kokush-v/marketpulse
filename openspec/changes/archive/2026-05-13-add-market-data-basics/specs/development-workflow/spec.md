## ADDED Requirements

### Requirement: Generated Frontend API Client

The system SHALL support generating frontend API client code from the backend OpenAPI schema for market-data endpoints.

Generated Orval output SHALL NOT be committed to the repository and SHALL be regenerated by command when needed.

#### Scenario: Generate market-data frontend client

- Given the backend exposes OpenAPI documentation for market-data endpoints
- When the developer runs the frontend API client generation command
- Then Orval shall generate typed frontend client code for the market-data endpoints
- And the generated client shall be based on the backend OpenAPI schema

#### Scenario: Keep generated client out of version control

- Given Orval has generated frontend API client output
- When repository changes are prepared for commit
- Then generated Orval output shall not be included in tracked source files
- And the repository shall provide a command that can regenerate the client output

#### Scenario: Frontend calls market-data backend

- Given market-data client code has been generated from OpenAPI
- When the frontend requests market-data quote or history data
- Then the frontend shall use the generated client or generated query hooks
- And the frontend shall not use hand-written Axios request functions for those market-data endpoints

#### Scenario: Backend contract changes

- Given a market-data API request or response schema changes
- When the frontend API client is regenerated
- Then the generated TypeScript types shall reflect the updated OpenAPI contract
